# Golden Hammer

## Tipo

Desarrollo

## Descripcion

Ocurre cuando un equipo o desarrollador se obsesiona con una tecnologia o patron especifico y lo aplica a todos los problemas, incluso cuando no es la herramienta adecuada. "Si todo lo que tienes es un martillo, todo te parece un clavo".

## Como reconocerlo

* Se usa una base de datos NoSQL para datos que son claramente relacionales (o viceversa).
* Se aplica un patron de diseño complejo (como Microservicios) a un sitio web de 3 paginas.
* El equipo se niega a considerar alternativas porque "siempre lo hacemos con X".

## Problemas que causa

* Soluciones innecesariamente complejas o ineficientes.
* Dificultad para escalar o adaptar el sistema a nuevos requisitos.
* Perdida de rendimiento y aumento de costos de infraestructura.

## Mal ejemplo

En bad-example.java se fuerza el uso de un patron complejo para una tarea que se podria resolver con un simple `if`.

## Buen ejemplo

En good-example.java se elige la solucion mas simple y directa para el problema actual.

## Como evitarlo

* Mantén una mente abierta y estudia diferentes tecnologias y patrones.
* Antes de elegir una herramienta, analiza los requisitos especificos del problema.
* No sigas modas tecnologicas sin entender si resuelven tu dolor actual.
