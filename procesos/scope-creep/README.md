# Scope Creep

## Tipo

Procesos

## Descripcion

Ocurre cuando el alcance de un proyecto crece sin control. Se van añadiendo pequeñas funcionalidades nuevas de forma constante, sin ajustar el tiempo ni el presupuesto, hasta que el proyecto se vuelve inmanejable.

## Como reconocerlo

* El proyecto nunca parece estar terminado.
* Cada semana hay una "pequeña peticion" adicional del cliente.
* La fecha de entrega se pospone continuamente.

## Problemas que causa

* El equipo se agota y pierde el enfoque.
* El codigo se ensucia para acomodar funciones que no estaban previstas originalmente.
* El proyecto puede quedarse sin presupuesto antes de lanzar lo basico.

## Mal ejemplo

Empezar haciendo una app para pedir pizzas y terminar intentando que tambien gestione la contabilidad del restaurante, el inventario y las vacaciones de los empleados, todo en el mismo lanzamiento.

## Buen ejemplo

Definir un MVP (Producto Minimo Viable) claro y no añadir nada nuevo hasta que esa base este en produccion. Las nuevas ideas se guardan para la "Fase 2".

## Como evitarlo

* Documenta y firma el alcance inicial.
* Cualquier cambio nuevo debe ser evaluado en tiempo y coste.
* Aprende a decir: "Es una gran idea, vamos a anotarla para la siguiente version".
