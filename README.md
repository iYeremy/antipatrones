# Biblioteca de Antipatrones

Esta es una guia practica y sencilla para identificar problemas comunes en el desarrollo de software.

## ¿Que es un antipatron?

Un antipatron es una solucion a un problema que parece buena en el momento, pero que a largo plazo genera mas daños que beneficios. Mientras que un patron de diseño es una "mejor practica", el antipatron es una "mala practica" que se repite con frecuencia y que debemos aprender a reconocer para evitarla.

## Categorias en este repositorio

* **Arquitectura**: Problemas en la estructura global del sistema y en como se comunican sus componentes.
* **Desarrollo**: Errores comunes al escribir codigo que afectan la limpieza, legibilidad y mantenimiento.
* **OOP (Orientacion a Objetos)**: Mal uso de los principios de objetos, clases y sus jerarquias.
* **Procesos**: Fallos en la gestion del equipo, la toma de decisiones y el flujo de trabajo.
* **Testing**: Pruebas automatizadas mal diseñadas que no protegen el sistema o que son dificiles de mantener.
